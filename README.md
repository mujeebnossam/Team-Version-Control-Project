# \## Workflow

# 1\. Created a GitHub repository.

# 2\. Cloned the repository locally.

# 3\. Created separate branches for individual modules.

# 4\. Added and committed module files.

# 5\. Pushed branches to GitHub.

# 6\. Created pull requests.

# 7\. Reviewed code changes.

# 8\. Merged pull requests into main.

# 9\. Created a merge conflict.

# 10\. Resolved the conflict and merged the changes.

# 11\. Documented the workflow in this README.

# 

# \## Conflict Resolution

# A merge conflict was created by modifying the same file in two branches. The conflicting changes were reviewed and combined into one final version.

# 

# \## Result

# Successfully implemented Git and GitHub version control with branching, commits, pull requests, merging and conflict resolution.
